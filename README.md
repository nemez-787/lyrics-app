🎸 Rock & Metal Vault (Music & Lyrics Library)

Rock & Metal Vault — это удобное веб-приложение для управления персональной музыкальной библиотекой, каталогом исполнителей, альбомов и текстов песен с поддержкой перевода. Проект разработан с акцентом на тяжелые музыкальные жанры, стилизован под мрачный и атмосферный рок-дизайн с использованием современных веб-технологий.

✨ Основные возможности
Каталог исполнителей (Artists):

Просмотр, добавление, редактирование и удаление музыкальных групп и исполнителей.

Предустановленная база данных с культовыми метал-коллективами (Metallica, Slipknot, Slayer, Tool, Static-X и др.).

Дискография (Albums):

Управление альбомами каждого исполнителя: добавление названий, годов релиза и обложек.

Треки и тексты песен (Tracks & Lyrics):

Хранение оригинальных текстов песен на английском языке и их переводов на русский.

Удобное управление треками с возможностью изменения порядка (Drag-and-Drop / стрелки навигации).

Интерактивные модальные окна для комфортного чтения текстов.

Резервное копирование (Backup):

Экспорт и импорт всей базы данных в формате JSON файлов прямо через интерфейс приложения.

Сохранение данных:

Все изменения автоматически сохраняются в локальном хранилище браузера (localStorage).

🛠 Технологии

HTML5 / CSS3

Tailwind CSS (для быстрой и адаптивной стилизации интерфейса)

JavaScript (Vanilla) (для логики приложения, управления состоянием и взаимодействия с localStorage)

FontAwesome (для иконок)

🚀 Установка и запуск
Поскольку проект работает полностью на стороне клиента (Client-side), вам не нужно настраивать сложные серверные окружения или базы данных.

Скачайте или клонируйте репозиторий на ваш компьютер, или откройте через ссылку https://nemez-787.github.io/lyrics-app/.

Убедитесь, что все файлы проекта находятся в одной папке (index.html, файлы стилей и скриптов).

Дважды кликните по файлу index.html, чтобы открыть его в любом современном веб-браузере (Google Chrome, Firefox, Edge, Opera) или перейдите по 
ссылке https://nemez-787.github.io/lyrics-app/ и загрузите файл .json  

💾 Резервное копирование данных

Если вы хотите перенести свою музыкальную библиотеку на другое устройство или сделать бэкап:

Воспользуйтесь кнопкой Экспорт (Export) в верхней панели приложения, чтобы скачать файл с данными в формате .json.

На новом устройстве или после очистки браузера нажмите Импорт (Import) и выберите сохраненный файл для восстановления всей коллекции.
